================
POSTMAN EXAMPLES
================


This folder contains the ecommerce_product_management_connector_collection_v18.postman_collection.json

A template with examples of standard calls from Sygel's product_management_connector module in v18

To use it:

- Import the template into your personal workspace
- Review the general variables, and configure them with those of the odoo to connect
- Increase the current value of the product_id variable as you create products

It has the following calls:

-  **External Create Product**: Call to create a product
-  **External Update Product**: Call to update a previously created product
