This module allows to set a default invoice policy for sale orders
coming through the ecommerce connector.

**Table of contents**

.. contents::
   :local:

Configuration
=============

1. Go to Ecommerce Connector > Connection
2. Go to a connection form view
3. Select a Sale Invoice Policy in the Invoice Policy field. This type
   will be set in all the sale orders coming through the connector
