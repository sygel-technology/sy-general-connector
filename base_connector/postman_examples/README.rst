================
POSTMAN EXAMPLES
================


This folder contains the base_connector_collection_v18.json. 

A template with examples of standard calls from Sygel's base_connector module in v18

To use it:

- Import the template into your personal workspace
- Review the general variables, and configure them with those of the odoo to connect
- Going up the current value of the sale_id variable as you create orders

It has the following calls:

-  **External Create Partner**: Call to get the data of a previously created customer
-  **External Read Partner**: Call to read the data of a previously created customer
-  **External Update Partner**: Call to update the data of a previously created customer
